Download

Get ProcessCraft 0.2.0

Two ways to get the same build: a per-user Windows installer, or a portable ZIP. Both are published on the release page, and neither is signed.

Open the 0.2.0 release page

Windows 10 or 11, 64-bit (x64). Nothing else was tested.

MSI or portable ZIP

The two files on the release page
FileSizeWhat it is
processcraft-0.2.0-windows-x64.msi56.5 MBInstaller. Installs for your account by default, with no administrator prompt, into %LOCALAPPDATA%\Programs\ProcessCraft. Adds a Start menu shortcut, makes ProcessCraft the handler for .processcraft files, offers it under "Open with" for .bpmn, and lets Win+R processcraft start it. Upgrades replace the older version. The first wizard page also offers "Everyone", which needs administrator rights and installs into Program Files.
processcraft-0.2.0-windows-x64-portable.zip66.5 MBThe two programs, the licenses and a README in one folder: unzip and run processcraft.exe. Nothing is registered, so file associations and shortcuts are yours to make.

Both contain processcraft.exe (the desktop app) and processcraft-cli.exe (the command line and MCP server; see Automation). To uninstall the MSI, use Windows "Installed apps".

Unsigned build

The files carry no code signature. Windows SmartScreen may therefore show "Windows protected your PC" and name an unknown publisher. That message says nobody has vouched for the publisher; it does not say anything about the contents. If you decide to run it anyway, choose "More info", then "Run anyway". Signing through a free open-source programme is planned but not done; see the roadmap.

You do not have to trust a download blindly. The source is public, and you can build it yourself.

Your files

  • A project is one .processcraft file: a ZIP package of versioned JSON and resources that holds your BPMN documents and diagrams, the dictionary, folders, comments and checkpoints. The format may still change while the project is pre-alpha.
  • Saves are atomic, a sidecar lock stops two writers, and recovery snapshots are kept outside the project.
  • Saving is qualified only on a fixed local Windows NTFS drive. Network shares, cloud-synced folders, removable drives and other file systems have not been tested; keep your projects on a local disk and keep backups.
  • Import and export: BPMN 2.0 XML in and out, SVG, PNG, PDF and draw.io out. Open a BPMN file with processcraft.exe model.bpmn or from the app.

Build from source

You need rustup (the repository pins Rust 1.98.1 and installs it for you) and Git. The first build fetches pinned forks of egui, winit and craft-libs; after that it builds offline.

git clone https://github.com/eliobenigni7/ProcessCraft.git
cd ProcessCraft
cargo run --release -p processcraft                  # desktop app
cargo run --release -p processcraft-cli -- --help    # command-line tool

The README has shortcuts and the three quality gates, and packaging/windows/package.ps1 builds the installer (it needs WiX 5.0.2).
