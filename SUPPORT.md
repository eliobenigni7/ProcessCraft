# Getting help

- **How do I…?** Start with the [documentation](https://eliobenigni7.github.io/ProcessCraft/docs/):
  the tutorial for analysts, the CLI and batch pages for developers, and the MCP pages for agents.
- **Is this verified?** The [status page](https://eliobenigni7.github.io/ProcessCraft/status.html)
  lists what has been checked, with measured numbers, and what has not.
- **Something is wrong:** open a [bug report](https://github.com/eliobenigni7/ProcessCraft/issues/new/choose).
  For a BPMN file from another tool that opens wrongly, use the BPMN interchange form.
- **An idea:** open a feature request and describe the problem it solves.
- **A security problem:** report it privately, as [SECURITY.md](SECURITY.md) explains.

ProcessCraft is pre-alpha and maintained by one person, so answers are best effort. A report with
the version, the steps and a small file that shows the problem is the fastest to act on.
